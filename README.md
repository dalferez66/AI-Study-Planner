# AI-Driven Study Architect 

A personalized study scheduling application that uses **Multivariate Linear Regression** to predict required study effort based on historical performance, subject difficulty, and target goals.

## How it Works
Unlike standard planners, this tool uses a `scikit-learn` machine learning model to calculate a **Learning Efficiency Coefficient**. It factors in:
- **Historical Data:** Your past exam performance.
- **Complexity:** Subject-specific difficulty ratings.
- **Time Constraints:** Real-time calendar deadlines and daily study caps.

## Tech Stack
- **Python version 3.x**
- **Scikit-Learn** (Used for Linear Regression)
- **Pandas** (Data Management)
- **Datetime** (Temporal Logic)
